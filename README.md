# AI Advertisement Creative Studio

A MERN-based AI Advertisement Creative Studio for creating, managing, and analyzing marketing creatives.

## Features

- AI-powered advertisement generation
- Image ad generation
- Video ad generation
- Creative templates
- Project management
- AI Creative Critic
- User authentication
- Brand Kit management

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Cloudinary
- Cloudflare AI APIs
- Magic Hour
